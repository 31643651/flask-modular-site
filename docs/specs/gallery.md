# SPEC：gallery（画廊模块）

> 本文件只锚定意图与对外承诺，不写实现细节。实现细节见 docs/architecture.md。

## 这个模块存在是为了什么

图片资产的浏览与个人化管理：让用户能按文件夹浏览/搜索/随机发现图片，在灯箱中查看，收藏喜欢的图片，并把界面偏好按用户跨端同步。

## 对外承诺的行为契约（用户视角可观察）

1. **浏览与搜索**：支持文件夹层级导航与关键词搜索；搜索结果文件夹带 `cover/count` 字段且与浏览口径一致（bug #8）。
2. **偏好保存后读回一致（B2 锚定）**：`POST /gallery/api/preferences`（包裹形态或裸字典）保存后，`GET` 读回为保存值而非默认值；未保存的键回退默认值（9 个默认偏好键：discover_enabled、discover_format、discover_rounded、discover_shape、discover_size、sidebar_transparency、lightbox_zoom_level、image_quality、autoplay_lightbox）。
3. **收藏 API 状态码矩阵（B6 锚定）**：未登录一律 401（含 check_favorite，与其余收藏接口口径一致）；收藏增删参数错误（空路径）400；成功 200。前端按 `success/message` 字段消费。
4. **收藏语义**：收藏幂等（重复添加返回"已收藏"）、取消后查询为假、路径反斜杠归一化为正斜杠；收藏按用户隔离。
5. **偏好并发安全（C5 锚定）**：多用户并发保存偏好不互相覆盖（读-改-写互斥保护）。
6. **多端同步**：登录用户的偏好设置在所有设备间自动同步。

## 边界与豁免

- 画廊功能受 `gallery_enabled` 开关控制，关闭时所有画廊请求重定向首页。
- 图片服务仅服务画廊根目录内的文件；画廊根路径来自配置。
- 未登录用户可访问画廊页面（浏览），但收藏/偏好写操作要求登录。
