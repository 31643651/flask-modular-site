# SPEC：index（首页模块）

> 本文件只锚定意图与对外承诺，不写实现细节。实现细节见 docs/architecture.md。

## 这个模块存在是为了什么

站点入口与公共门面：给登录后的用户提供统一首页导航，并承载三类"挂在首页上"的公共能力——壁纸、外部页面挂载、公共配置只读接口。

## 对外承诺的行为契约（用户视角可观察）

1. **首页导航**：登录用户访问 `/` 看到各功能模块入口；未登录访问被重定向到登录页。
2. **壁纸展示**：壁纸启用且配置了有效路径时，首页以随机图片作为背景；未启用或路径无效时无壁纸。
3. **壁纸配置权限（C3 锚定）**：`POST /api/wallpaper/config` 仅超级管理员可改——未登录 401、普通登录用户 403（统一错误格式 `{"code","data","msg"}`）、超管未过二次验证 302 跳验证页、超管 200 且配置生效；`enabled` 为布尔或字符串 `"true"/"false"`，字符串 `"false"` 不再被当真值。
4. **壁纸文件服务安全**：`GET /static/wallpaper` 公开服务；解析路径逃逸项目根或落入系统敏感目录时返回 403（HTTPException 直接透传，不被吞成 404）；路径不存在返回 404。
5. **页面挂载（ADR-0002 锚定）**：管理员配置的外部文件/目录通过 `GET /<page_name>` 服务：目录挂载根与含 index.html 的子目录在无尾斜杠访问时 302 重定向到带尾斜杠路径（保证相对资源正确解析）；挂载 HTML 中以站根绝对路径（单个 `/` 开头）的双引号 `src`/`href` 引用被重写为 `/<name>/...` 前缀路径（`//`、裸 `/`、外链、`data:`、锚点、相对引用不动）；静态资源按显式 MIME 表返回（`.js/.mjs→text/javascript` 等，guess_type 兜底）；包含 `..` 或路径穿越的请求被拒绝（403）；挂载路径必须在项目根内且不落入敏感目录。运行时动态拼绝对路径取资源的站点与 history 路由 SPA 深链接不在兼容范围（备案限制）。已知正则边界：重写匹配未锚定属性名左边界，`data-href`/`data-src`/内联 JS 字符串形态会被一并改写（保守设计的已知取舍，见 ADR-0002）。
6. **公共配置只读接口**：`GET /api/wallpaper/config`、`GET /api/mounted-pages` 为公开只读接口（用于首页展示），不泄露敏感路径。

## 边界与豁免

- 壁纸与挂载页面**读取**公开（首页需匿名可渲染），**写入**仅超级管理员/管理员。
- 本模块不管理挂载页面的增删（那是 admin 模块的职责），只提供服务与只读接口。
- 目录浏览页跳过隐藏文件与敏感目录条目。
