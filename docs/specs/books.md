# SPEC：books（书籍管理模块）

> 本文件只锚定意图与对外承诺，不写实现细节。实现细节见 docs/architecture.md。

## 这个模块存在是为了什么

本地书库的阅读入口：按关键词找书、看详情、逐章阅读，并正确服务书籍自带的静态资源。

## 对外承诺的行为契约（用户视角可观察）

1. **书籍搜索**：`GET /book/search?q=关键词` 返回匹配书籍；分页链接对特殊字符（中文、空格、符号）正确编码且可达（分页往返不丢参数）。
2. **封面服务**：每本书有封面 URL；子目录书的封面可访问；路径穿越被拒绝；封面缺失返回 404 而非崩溃。
3. **章节阅读**：按书籍 ID 与章节号阅读；不存在的章节/书籍给出明确错误。
4. **静态资源**：书籍目录内静态文件按正确 MIME 内联返回。

## 边界与豁免

- 书籍数据来自 SQLite books 表；路径配置来自 config.json。
- 书籍静态资源仅服务书籍目录内文件，不做目录列举。
