# ADR-0011: 页面与静态资源缓存策略及画廊渲染加速

- 状态：已接受
- 日期：2026-11-21

## 背景

性能基线（`scripts/perf_baseline.py`，本机 127.0.0.1，登录态，P50）：

| 资源 | 现状 |
|---|---|
| `/`、`/user/profile`、`/book` | 15~16ms（达标） |
| `/gallery` | **155ms**（服务端渲染慢） |
| `/gallery/favorites` | 26ms（服务端不慢，慢在资源） |
| `/static/gallery/*.css/js` | 15ms，响应头 **`Cache-Control: no-cache`** —— 每次刷新全部重新协商 |
| `/gallery/image/*`（图片） | 无任何缓存头 —— 每次刷新重新下载原图 |

两个根因：
1. **全站无有效 HTTP 缓存**：Flask `send_file` 默认 `no-cache`，浏览器每次刷新对所有 CSS/JS/图片重新发协商请求；收藏页以原图渲染，每次刷新重新下载大图 → 用户感知"每次刷新都要半天"。
2. **`/gallery` 服务端 155ms**：`_build_gallery_data` 对每个子文件夹调用 `count_images_in_folder`/`get_first_image`，二者递归遍历整棵目录树；`get_folder_scan` 每次调用都 `folder.stat()` 取 mtime 判缓存 → 每次请求对 6000+ 文件做数千次 `stat` 系统调用（Windows 上尤其慢）。

约束：页面是动态的（用户/收藏/偏好），不能整页缓存；静态资源与图片改动后必须能及时生效（不能给静态资源无限缓存却不带版本号）。

## 决策

**1. 分层 HTTP 缓存策略**（`security.py` 统一在安全头里追加）：

| 资源 | Cache-Control |
|---|---|
| HTML 页面（`text/html`） | `no-store`（动态页面不缓存，防陈旧数据） |
| `/static/` 且 URL 带版本号 `?v=` | `public, max-age=31536000, immutable` |
| 其它 `/static/`（favicon、壁纸等） | `public, max-age=3600` |
| 图片（`image/*`：画廊/反馈/书籍/壁纸） | `public, max-age=86400`（配已有 ETag） |
| JSON/其它 API | 不设置（保持默认，避免 API 被缓存） |

**2. 静态资源版本化**：`app.py` 增加 `static_url(filename)` 上下文函数，输出 `/static/<path>?v=<mtime>`；画廊 3 个静态引用（`gallery.css`、`gallery-page.js`、`favorites.css`）改用该函数——文件变更 mtime 变化 → URL 变化 → 浏览器立即取新文件，未变更时直接用 1 年强缓存。

**3. 画廊扫描加速**：`get_folder_scan` 的 mtime 校验加 2 秒短 TTL（2 秒内直接命中缓存、跳过 `stat`）；`_build_gallery_data` 的「子目录计数 + 封面」结果按 `(目录, mtime)` 缓存 5 秒。代价：新增/删除图片后统计与封面最多滞后约 5 秒（可接受，页面刷新即有）。

**4. 预加载**：画廊首页 head 对首个文件夹封面加 `<link rel="preload" as="image">`，缩短首屏缩略图等待。

**放弃的备选**：
- ①全站给 `/static/` 加 `immutable` 一年缓存但不带版本号——前端改动后用户长期拿旧文件，弃；
- ②只把 `no-cache` 改为 `must-revalidate`——仍是每次协商，不解决重复下载，弃；
- ③页面整页缓存（按 URL 缓存 HTML）——动态内容（收藏数/偏好/登录态）会串用户，且安全风险高，弃。

**范围外**：CDN/反向代理层缓存、图片压缩转码、前端虚拟滚动。

## 后果

**正面**：二次刷新时 CSS/JS 直接命中本地缓存（0 请求）；图片 1 天内不重新下载（经 ETag 过期后协商）；`/gallery` 从 ~155ms 降到 20ms 量级；HTML 明确 `no-store` 避免陈旧页面。

**负面/代价**：
- 同名图片被替换后，浏览器最多 1 天看到旧图（需强刷）；经 ETag/Last-Modified 协商，超过 1 天自动更新；
- 目录内容变化后画廊统计/封面最多滞后 5 秒；
- 静态资源 URL 带 `?v=`，对外链接形态变化（仅内部模板引用，无对外 API 契约）。

**对契约/goldens**：不改任何 API 响应结构与 goldens；新增响应头属可观察行为（本 ADR 授权）。新增测试锚定缓存头规则；画廊重写锚定测试中静态引用断言需适配版本化 URL（断言意图不变：资源外置 + 注入行在前）。

**验证口径**：`scripts/perf_baseline.py` 复测（HTML 页面 P50 ≤100ms、`/gallery` ≤200ms、静态/图片头含 max-age）；全量 `py -3.12 -m pytest tests/ -q` 0 failed。
