# ADR-0012: 首页服务端渲染与发现区限量缓存

- 状态：已接受
- 日期：2026-11-21

## 背景

用户在真实浏览器中的可感知问题（与 ADR-0011 的服务端 P50 无关）：

1. **发现区"加载中"要等 1 秒多**：`GET /gallery/api/random-images` 实测 **1426ms**、返回 **488 张图**（遍历整棵画廊树、每个 ≥4 图文件夹各抽 4 张，无结果缓存）；随后 488 张原图逐个加载。
2. **主页面挂载入口"半天才出来/经常缺失"**：入口由前端 `fetch('/api/mounted-pages')` 后 `innerHTML` 渲染，依赖 JS 成功执行与接口返回；接口失败或慢 → 入口缺失。
3. **背景壁纸"慢/不加载"**：前端 `fetch('/api/wallpaper/config')`（实测 317ms）后才设置背景，且图片 URL 拼 `?t=${Date.now()}` **每次刷新强制重新下载**（约 1MB）；fetch 失败时背景静默不显示。

`/api/mounted-pages` 与 `/api/wallpaper/config` 本身并不慢（4ms/317ms），慢在"前端必须等接口回来才渲染"这一结构性依赖，以及随机图的全树扫描与无限量渲染。

## 决策

**1. 首页改为服务端渲染关键内容**（`index()` 路由）：
   - `mounted_pages`（按 `mounted_pages_enabled` 过滤）直接传入模板，`{% for %}` 输出入口链接——**入口随 HTML 立即可见**，删除前端 `loadMountedPages()` 的渲染依赖（保留 `/api/mounted-pages` 接口兼容）；
   - `wallpaper_url` 由服务端解析（配置启用且目录存在时随机选一张文件，输出 `/static/wallpaper?img=<文件名>`），模板内联 `style="background-image:url(...)"` 并加 `<link rel="preload" as="image">`——**背景随 HTML 立即开始加载**，不再依赖前端 fetch；壁纸开关仍可前端切换（复用服务端 URL）。

**2. 壁纸按文件名寻址 + 可缓存**：`/static/wallpaper` 支持 `?img=<文件名>`（仅允许壁纸目录内已存在文件，拒绝路径分隔符/不存在 → 404）；无 `img` 时保持随机行为。响应按 `image/*` 走 ADR-0011 的 1 天缓存——同一文件名再次出现直接命中缓存；前端不再拼 `Date.now()` 时间戳。

**3. 发现区限量 + 缓存**：
   - `/gallery/api/random-images` 结果按（画廊根）缓存 **300 秒**；命中直接返回；
   - 返回上限 **8 个文件夹 × 4 张 + 根目录 4 张 = ≤36 张**（shuffle 后取前 8 个文件夹）——发现区可视区域仍有多样图片，但资源总量从 488 张降到 ≤36 张；
   - `get_all_subfolders_recursive` 结果缓存 **300 秒**（目录新增/删除最多 5 分钟后反映到发现区，可接受）。

**4. 图片加载策略**（保持）：发现区前 8 张 `eager`、其余 `loading="lazy"`；画廊首页对首个文件夹封面上 `rel=preload`（ADR-0011 已加）。

**放弃的备选**：
- ①只把随机图缓存 TTL 调大、不限量——488 张原图仍要下载，首屏依旧慢，弃；
- ②为非浏览器场景保留前端渲染——两套渲染路径易漂移，且服务端渲染是 SSG 式零等待，弃；
- ③壁纸保留 `?t=Date.now()` 每次随机——随机性与缓存互斥，改为"服务端随机选一张 + 按文件名缓存"，刷新随机性降低（同一文件重复命中），但换来背景秒出，弃原方案。

**范围外**：图片压缩/缩略图生成（无图像库依赖）、发现区虚拟滚动、CDN。

## 后果

**正面**：首页入口与背景在 HTML 到达时即存在（无需等 JS/fetch）；发现区接口首次扫描后 5 分钟内 <50ms 命中，图片总量降为 ≤36 张，视口内图片快速加载完；壁纸图缓存后二次访问 0 请求；API 失败不再导致入口/背景缺失。

**负面/代价**：
- 发现区随机性下降（最多 36 张、5 分钟内重复同一批）——可接受的产品折衷；
- 壁纸每次刷新不再必然换图（服务端随机 + 缓存），如需换可刷新超过缓存寿命或手动切换；
- 目录变化 5 分钟后反映到发现区（画廊浏览页仍实时）。

**契约/goldens**：不改任何既有 API 响应结构（`random-images` 仍返回 `{success, images[]}`，只是数量上限变化；mounted-pages/wallpaper 接口保留）；新增测试锚定服务端渲染与缓存行为；无 golden 涉及。

**验证口径**：浏览器实测首页入口/背景随 HTML 出现、发现区"加载中"消失且二次调用 <50ms；`py -3.12 -m pytest tests/ -q` 0 failed。
