# ADR-0010: 统一错误页：404/403/500 页面分流与 API JSON 保持

- 状态：已接受
- 日期：2026-11-21

## 背景

`app.py:238-246` 的全局错误处理对 404/500 **一律返回 JSON**（`{"error": "Not found", "code": 404}` / `{"error": "Internal server error", "code": 500}`），403 无 handler（走 Werkzeug 默认英文页）。用户实际遇到：挂载了一个目标不可访问的页面（如 `/rrr` 指向不存在的 `rrrr`），浏览器整页导航直接看到裸 JSON——既不好看也不像正常站点。项目当前没有任何 404/403/500 页面模板；最接近的现成提示页是 `Module/ipguard/templates/ipguard/banned.html`（卡片+图标+标题+描述，适配暗夜模式）。

约束：
- 前端大量 fetch 调用（画廊、管理后台、反馈等）依赖 JSON 错误体解析，**页面化不能波及 API**；
- 各业务路由自己 `jsonify` 的错误（如画廊 `{"success": false, "message": ...}`）不经过全局 handler，不应改动；
- `tests/test_integration.py:433` 现有断言 404 → JSON，行为变更需同步更新（本 ADR 授权）。

## 决策

**错误响应按请求类型分流**（404/403/500 统一）：

1. **页面请求**（浏览器导航）→ 渲染统一错误页 `Module/templates/errors/error.html`：卡片式纯提示（无按钮、无技术细节），沿用 `banned.html` 的字体/配色/暗夜模式（`darkMode` cookie）与响应式断点；按状态码显示：404「页面不存在」、403「访问被拒绝」、500「服务器出错了」。
2. **API 请求** → 保持 JSON 形态 `{"error": "<message>", "code": N}`（404/500 文案与现状逐字一致，403 新增同形态），**API 契约零变化**。

**JSON 判定规则**（满足任一条即返回 JSON，否则返回错误页）：
- `request.is_json`；
- 路径含 `/api/` 段或结尾为 `/api`（项目 API 路由形态：`/gallery/api/*`、`/admin/activity/api`、`/user/api/*`、`/admin/ip/api/*`）；
- 方法非 GET/HEAD（页面导航恒为 GET；POST/PUT/DELETE 多为前端 fetch）；
- `Accept` 头不包含 `text/html`（Werkzeug 测试客户端无 Accept 时归为 JSON，保持既有测试口径）。

**放弃的备选**：
- ①全部返回错误页——所有 fetch 的 `resp.json()` 会解析失败，波及面大，弃；
- ②全部返回 JSON（即现状）——不满足「不要暴露原生 JSON 错误」的诉求，弃；
- ③改造 `banned.html` 为通用错误模板复用——封禁页还承担倒计时/永久封禁等专属逻辑，混用会引入回归风险，弃；改为新建独立模板、复用其视觉风格。

**范围外**：业务路由内部的业务错误 jsonify（不动）、ipguard 封禁/限流页（不动）、debug 模式下 Werkzeug 调试器页面（开发态行为，不动）。

## 后果

**正面**：浏览器导航至不存在/无权/出错的页面得到与站点风格一致的中文提示页；挂载页目标缺失（`abort(404)`）不再暴露裸 JSON；API 客户端行为完全不变。

**负面/代价**：错误页模板需随暗夜模式与全站配色同步维护（单文件、复用同一套 CSS 变量约定，成本低）；`tests/test_integration.py` 的 404 JSON 断言需按本 ADR 拆分为「API 仍 JSON」+「页面返回 HTML」两条（断言不降级）。

**对契约/goldens**：无 golden 涉及错误页（gallery/admin 契约均为成功响应结构）。`test_integration.py::test_404_handler_returns_json` 拆分为双断言属本 ADR 授权的测试更新，其余测试零改动。

**验证口径**：新增 `tests/test_error_pages.py`（三状态码 × 页面/API 矩阵、模板纯提示无按钮、暗夜模式脚本、不泄露技术信息）；全量 `py -3.12 -m pytest tests/ -q` 0 failed；浏览器实测挂载缺失路径显示错误页、API 404 仍为 JSON。
