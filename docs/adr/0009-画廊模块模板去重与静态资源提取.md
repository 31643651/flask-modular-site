# ADR-0009: 画廊模块模板去重与静态资源提取

- 状态：已接受
- 日期：2026-11-21

## 背景

画廊模块存在三份大模板与一处死副本：

- `gallery/index.html`（2443 行）：**实际被路由引用**的唯一浏览页（目录+网格+发现+设置侧栏）。
- `gallery/gallery.html`（2442 行）：与 index.html **重复率 >99% 的死副本**——`git diff` 仅行号偏移差异，且**零路由引用**（CHANGELOG:157 已明示"实际使用的模板是 index.html 而非 gallery.html"），无任何测试引用。
- `gallery/favorites.html`（1116 行）：收藏页，其灯箱/缩放/滑动/通知/收藏心形体系是 index 逻辑的简化变体，又复制了一遍。

三模板 CSS/JS **100% 内联**（index 的 `<style>` 895 行 + `<script>` 1307 行），导致：同一灯箱/滑动/偏好/发现逻辑维护多份、修 bug 需多处同步（确认框死按钮 T2 就是多模板同步修复的典型代价）、模板文件大到难以整体推理。同时 index 与 gallery.html 两份副本**已经漂移过一次**的风险持续存在——工作区当前的"滑动原地换图"未提交改动就是在两份副本上重复落地的。

## 决策

**行为不变的结构重写**，四步，全部落在既有契约与 golden 锚定的行为边界内：

1. **删除死副本 `gallery.html`**：零路由引用、零测试引用，直接移除；`index.html` 成为唯一浏览页模板。
2. **提取静态资产**：新建 `Module/gallery/static/`（蓝图补 `static_folder`），把不含 Jinja 变量的公共 JS/CSS 拆为静态文件（预计 `js/discover.js`、`js/lightbox.js`、`js/favorites.js`、`js/preferences.js`、`js/common.js` 与 `css/gallery.css` 等，按既有代码块边界切分）。**保留内联的最小注入行**（契约测试正则锚定，文本形态不可改）：`const serverPreferences = {{ user_preferences | tojson }};`、`const serverDeviceSpecific = {{ device_specific | tojson }};`、`window.csrfToken = {{ csrf_token | tojson }};`。
3. **提取 Jinja 片段**：`_lightbox.html`、`_sidebar_settings.html`、`_breadcrumbs.html` 等公共 include，消除 HTML 结构重复（favorites 与 index 的灯箱结构差异用参数化 include 表达，无法统一的差异保留在页面模板内）。
4. **路由层去重**：三份完全相同的 `check_gallery_enabled` before_request 抽为 `Module/gallery/` 内公共装饰器供三蓝图复用；`sanitize_path`/`_resolve_subdir` 下沉 `Module/core/gallery_service.py`（纯代码移动，monkeypatch 点与路径语义不变）。

**资产 URL 口径**：静态资源走**全局 `/static/...`**（Blueprint 配 `static_folder` 时 Flask 的 `static_url_path` 设为 `/static/gallery`），与壁纸等既有资产同前缀。原因：ipguard `WHITELIST_PREFIXES` 仅豁免 `/static/`、`/favicon.ico` 等（`Module/ipguard/middleware.py:19-25`），无任何 gallery 前缀豁免；若走 `/gallery/static/...` 蓝图默认前缀会把每个资产请求计入第二防线限流统计（属新行为变更），选 `/static/` 前缀避免该问题、无需改 ipguard。

**语义保留承诺**：发现算法按 `docs/superpowers/specs/` 摸底报告锚定的 15 步语义清单逐步等价保留（含服务端随机采样、eager/lazy 分段、`discover:images-rendered` 重设显示参数、到底提示双条件、环形灯箱导航、偏好双写闭环、resize 重跑、reset 清 7 键）；工作区未提交的**滑动原地换图改动 6 点语义**（innerWidth 基准、直接换 `src` 不走 openLightbox、手动推进 `_discoverCurrentIndex`、手动更新文件名、手动 `checkFavoriteStatus`、对侧滑入序列）逐点保留并随后续提交入库。

**放弃的备选**：
- ①保留 gallery.html 改为 `{% extends 'gallery/index.html' %}` 空壳——仍留一个无引用模板文件，留着就会被再次编辑产生漂移，不如直接删；
- ②保持全内联只做片段 include——省去 static 路径问题，但 JS 千行级重复（index vs favorites 灯箱/滑动/收藏体系）仍在模板内，去重收益大减，弃；
- ③把 favorites 的灯箱与 index 灯箱合并为完全同一实现——两者列表源（`galleryItems` vs `_discoverImages`）与收藏初始化语义（favorites 无条件点亮 vs index 按状态查询）本质不同，强行合并需要大改参数与分支、增加行为回归风险，弃：用"参数/配置对象可覆盖的共享核心 + 页面级差异函数"折中，差异部分保留在页面模板。

**不改的东西**：三份 golden（`gallery_preferences_get.json`、`gallery_favorites_status_codes.json`）与全部 gallery 测试的断言、monkeypatch 点（`gallery_service.PREFERENCES_FILE` 等）、模板内联注入三行的文本形态、favorites.html 的 `confirmDialog` 先捕获后关闭时序、浏览页服务端渲染目录/文件名文本（纯客户端渲染会打破 path_traversal 测试）、`serve_image` 的 `relative_to` 403/404 语义、收藏 `\`→`/` 归一化、`gallery_enabled` 三蓝图重定向行为。

## 后果

**正面**：消除 ~2442 行死副本与两模板间的全量重复；灯箱/滑动/发现/偏好 JS 收敛为单一权威实现（下次确认框类修复只需改一处）；浏览器缓存静态 JS/CSS 降低重复下载；模板缩回可整体阅读的规模；路由层守卫单一实现。

**负面/代价**：
- 静态文件带来**缓存新鲜度**问题——改 JS 需要浏览器缓存失效（开发期 Flask 静态路由带 last-modified，生产如需强版本化后续追加 hash 查询串，本轮不做属 YAGNI）；
- Jinja 注入三行仍在模板内，JS 大部分外移后存在"注入行 vs 外部 JS 执行顺序"的隐式依赖——外部 JS 必须在注入行**之后**加载（`<script src>` 顺序保证），模板评审需盯住该顺序；
- 行为等价性依赖 15 步语义清单人工对照 + 全量回归，无 DOM 级自动化测试兜底（项目现状无浏览器自动化），残余风险由浏览器端手工回归覆盖。

**对契约/goldens**：**零改动**。两份 golden、`tests/contracts/test_contracts.py` 两组画廊契约、`test_gallery_preferences/search/path_traversal/atomic_writes/confirm_dialog_templates` 全部断言保持原样，重写以"514 基线全绿 + 新增等价锚定测试"为验收。

**范围外**：发现算法行为调整、图片格式/质量策略、ipguard 白名单变更、favorites 与 index 合并为单页。

- **G3/G4**：落地时确认原 `<script>` 是**单个 `DOMContentLoaded` 闭包**，按函数跨文件切分会改变闭包作用域语义（违背行为不变），故 JS **整块**提取为 `static/gallery/js/gallery-page.js`（注入三行仍内联在模板且位于 src 之前；锚定测试 `test_swipe_inplace_semantics_preserved` 锁 6 点滑动语义）；CSS 提取为 `static/gallery/css/gallery.css`。多文件细分作为后续可选重构不在本轮。
- **G5**：favorites CSS 提取为 `static/gallery/css/favorites.css`；两页灯箱 markup 参数化 include `_lightbox.html`（`lightbox_favorite_title` 变量区分「收藏/取消收藏」）。**favorites 的 JS 保留内联**——`tests/test_confirm_dialog_templates.py` 以模板源码锚定 `confirmDialog`「先捕获后关闭」时序（ADR-0006 根因 A 的防回归锚点），外置须改动该测试锚点，按纪律本轮不动；`_sidebar_settings.html` 未提取（侧栏 markup 仅 index 存在，无共享对象）。
